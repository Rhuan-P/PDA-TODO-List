## 🚀 Início Rápido

### 1. Clonar o Repositório
```bash
git clone https://github.com/Rhuan-P/PDA-TODO-List.git
cd PDA-TODO-List
```

### 2. Instalar Dependências
```bash
npm install
```

### 3. Configurar Supabase

#### Criar Projeto Supabase
1. Acesse [supabase.com](https://supabase.com)
2. Crie novo projeto: `pda-todo-list`
3. Aguarde criação (2-3 minutos)

#### Configurar Tabela
1. No dashboard → **SQL Editor**
2. Execute este SQL:

```sql
CREATE TABLE IF NOT EXISTS tarefas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    titulo VARCHAR(255) NOT NULL,
    descricao TEXT,
    status VARCHAR(20) NOT NULL DEFAULT 'pendente' CHECK (status IN ('pendente', 'em_andamento', 'concluida')),
    criado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    atualizado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_tarefas_status ON tarefas(status);
CREATE INDEX IF NOT EXISTS idx_tarefas_criado_em ON tarefas(criado_em DESC);

ALTER TABLE tarefas ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all operations on tarefas" ON tarefas FOR ALL USING (true) WITH CHECK (true);

INSERT INTO tarefas (titulo, descricao, status) VALUES
    ('Exemplo de tarefa', 'Esta é uma tarefa de exemplo', 'pendente'),
    ('Outra tarefa', 'Mais uma tarefa para demonstração', 'em_andamento'),
    ('Tarefa concluída', 'Uma tarefa que já foi finalizada', 'concluida')
ON CONFLICT DO NOTHING;
```

#### Obter Credenciais
1. **Project Settings** → **API**
2. Copie **Project URL** e **anon public key**

### 4. Configurar Ambiente
```bash
# Copiar arquivo de exemplo
cp .env.example .env

# Editar .env com suas credenciais
SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_ANON_KEY=sua_chave_anon_aqui
```

### 5. Executar Localmente
```bash
# Modo desenvolvimento
npm run dev

# Modo produção
npm start
```

### 6. Acessar Aplicação
- **Frontend:** http://localhost:3000
- **API Docs:** http://localhost:3000/api/docs
- **Health Check:** http://localhost:3000/api/health

## 📚 Documentação da API

### Endpoints Principais

#### Tarefas
- `GET /api/tarefas` - Lista todas as tarefas
  - Filtro: `?status=pendente`
- `POST /api/tarefas` - Cria nova tarefa
  ```json
  {
    "titulo": "Nova tarefa",
    "descricao": "Descrição detalhada",
    "status": "pendente"
  }
  ```
- `GET /api/tarefas/:id` - Busca tarefa por ID
- `PUT /api/tarefas/:id` - Atualiza tarefa
- `DELETE /api/tarefas/:id` - Remove tarefa

#### Sistema
- `GET /api/health` - Health check da API
- `GET /api/info` - Informações da API

### Status Válidos
- `pendente` - Tarefa não iniciada
- `em_andamento` - Tarefa em progresso
- `concluida` - Tarefa finalizada

### Respostas HTTP
- `200` - Sucesso
- `201` - Criado com sucesso
- `400` - Requisição inválida
- `404` - Recurso não encontrado
- `500` - Erro interno do servidor

## 🐛 Troubleshooting

### Problemas Comuns

**1. Erro de conexão Supabase**
- Verifique variáveis `.env`
- Confirme se projeto Supabase existe
- Valide se tabela foi criada

**2. Deploy falhando no Vercel**
- Verifique se variáveis estão configuradas no dashboard Vercel
- Confirme se `.env` não está no `.gitignore`

**3. Frontend não carrega**
- Verifique se arquivos estáticos estão em `/public`
- Confirme se `vercel.json` está configurado corretamente

### Logs e Debug
```bash
# Ver logs do servidor
npm start

# Testar conexão Supabase
node quick_test.js
```

## 🚀 Recursos Avançados

### Real-time Subscriptions
O Supabase suporta subscriptions em tempo real:
```javascript
// Exemplo de subscription
const subscription = supabase
  .channel('tarefas_changes')
  .on('postgres_changes', 
    { event: '*', schema: 'public', table: 'tarefas' },
    (payload) => console.log('Mudança:', payload)
  )
  .subscribe();
```

### Backup e Restore
- **Backup automático:** Supabase faz backup diário
- **Exportar dados:** SQL Editor → Export
- **Importar dados:** SQL Editor → Import

### Performance
