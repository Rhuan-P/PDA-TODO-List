# 🚀 Setup Automático Supabase

## Passo 1 - Criar Projeto (2 minutos)

1. **Acesse**: https://supabase.com
2. **Login**: Use sua conta Google/GitHub
3. **New Project**: Botão roxo no dashboard
4. **Organization**: Selecione sua org ou crie nova
5. **Project Name**: `pda-todo-list`
6. **Database Password**: Crie uma senha forte e **guarde-a**
7. **Region**: Escolha `South America East (São Paulo)` 
8. **Wait**: Aguarde 2-3 minutos o setup

## Passo 2 - Executar Schema (1 minuto)

1. No dashboard → **SQL Editor** (ícone de tabela)
2. **New query** → botão superior direito
3. **Copie** o conteúdo abaixo:
```sql
-- Schema para tabela de tarefas no Supabase
CREATE TABLE IF NOT EXISTS tarefas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    titulo VARCHAR(255) NOT NULL,
    descricao TEXT,
    status VARCHAR(20) NOT NULL DEFAULT 'pendente' CHECK (status IN ('pendente', 'em_andamento', 'concluida')),
    criado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    atualizado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_tarefas_status ON tarefas(status);
CREATE INDEX IF NOT EXISTS idx_tarefas_criado_em ON tarefas(criado_em DESC);

CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.atualizado_em = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER update_tarefas_updated_at 
    BEFORE UPDATE ON tarefas 
    FOR EACH ROW 
    EXECUTE FUNCTION update_updated_at_column();

ALTER TABLE tarefas ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow all operations on tarefas" ON tarefas
    FOR ALL USING (true) WITH CHECK (true);

INSERT INTO tarefas (titulo, descricao, status) VALUES
    ('Exemplo de tarefa', 'Esta é uma tarefa de exemplo para testar o sistema', 'pendente'),
    ('Outra tarefa', 'Mais uma tarefa para demonstração', 'em_andamento'),
    ('Tarefa concluída', 'Uma tarefa que já foi finalizada', 'concluida')
ON CONFLICT DO NOTHING;
```
4. **Run** → Execute o SQL

## Passo 3 - Obter Credenciais (30 segundos)

1. **Project Settings** → ícone de engrenagem ⚙️
2. **API** → menu lateral
3. **Copie** estas duas informações:

```
✅ Project URL: https://[seu-id].supabase.co
✅ anon public: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## Passo 4 - Configurar Ambiente (1 minuto)

1. **Crie** arquivo `.env` na raiz:
```bash
# Configurações do Supabase
SUPABASE_URL=https://[seu-id].supabase.co
SUPABASE_ANON_KEY=eyJ...sua_chave_completa_aqui
```

2. **Substitua** `[seu-id]` e `eyJ...` com suas credenciais

## Passo 5 - Testar Local (30 segundos)

```bash
npm run dev
```

## Passo 6 - Configurar Vercel (1 minuto)

1. **Acesse**: https://vercel.com/dashboard
2. **Seu projeto** → `pda-todo-list`
3. **Settings** → **Environment Variables**
4. **Adicione**:
   - `SUPABASE_URL`: https://[seu-id].supabase.co
   - `SUPABASE_ANON_KEY`: eyJ...chave_completa
5. **Redeploy** automático
